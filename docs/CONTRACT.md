# 对拍工作台 v1：协作接口

Windows 10/11, JDK 21. Electron + React + local Monaco. Spring Boot, MyBatis, SQLite. All runtime resources local. No network or AI feature. Data directory: duipai.db, images/, work/, settings.json.

## HTTP

Backend binds 127.0.0.1, dynamic port supported via --server.port=0. Environment DUIPAI_TOKEN required (random token generated by Electron); DUIPAI_DATA_DIR optional. Every /api/** request including SSE and images requires HttpOnly cookie duipai_token OR X-Duipai-Token header. No unrestricted CORS. Electron loads bundled frontend from backend static content in production, Vite proxy in dev. Backend stdout emits DUIPAI_READY:<port> after start. GET /api/health returns {status:"ok", javaVersion, dataDir}. POST /api/shutdown requests engine cancellation and graceful application exit, only with valid token.

- GET /api/problems -> ProblemSummary[] {id,title,updatedAt}
- POST /api/problems body {title} -> Problem
- GET /api/problems/{id} -> Problem
- PUT /api/problems/{id} body full Problem excluding timestamps -> Problem
- DELETE /api/problems/{id} -> 204 (UI asks confirmation)
- POST /api/images multipart field file -> {url:"/api/images/<uuid>.<ext>"}; GET that url -> binary
- GET /api/settings/layout -> object or {}; PUT /api/settings/layout body object -> object
- GET /api/problems/{id}/runs -> JobSnapshot[] newest first (can omit large content from list)
- GET /api/runs/{id} -> complete snapshot including codes snapshot and settings
- POST /api/jobs body {problemId,replaySeed?:string} -> JobSnapshot; 409 if another job active
- GET /api/jobs/{id} -> JobSnapshot
- GET /api/jobs/{id}/events -> SSE event name progress, JSON JobSnapshot, interval 300ms and immediate completion
- POST /api/jobs/{id}/cancel -> JobSnapshot
- GET /api/runs/{id}/export/{input|generator|brute|optimized|generator-stderr|brute-stderr|optimized-stderr} -> UTF-8 text attachment

Problem = {id,title,statement,codes:{generator,brute,optimized},settings:{rounds,startSeed,parallelism,generatorTimeoutMs,bruteTimeoutMs,optimizedTimeoutMs},updatedAt}. Seed is ALWAYS string (signed 64-bit integer), empty/null means random. Defaults: rounds=1000, seed=null, parallelism=4, timeouts=5000/10000/2000. Fresh templates use public class Main; generator parses args[0]. Start must save frontend edits before POST jobs.

JobSnapshot = {id,problemId,state,verdict,message,startedAt,completed,total,elapsedMs,roundsPerSecond,maxOptimizedMs,seed,round,input,generator,brute,optimized,firstDifference,compileErrors,codes,settings}. state: COMPILING/RUNNING/FINISHED. verdict: null/PASS/WA/RE/TLE/OLE/BRUTE_ERROR/GENERATOR_ERROR/CE/CANCELLED/INTERNAL_ERROR. round is 1-based display index. completed = number fully judged. ProcessResult = {stdout,stderr,elapsedMs,exitCode,timedOut,outputLimited}; missing program results may be null. firstDifference={line,expected,actual} (1 based) or null. compileErrors=[{role,output,diagnostics:[{line,column,message}]}]. Each content block >1MiB frontend previews 1MiB and links export endpoint. SSE/persist snapshot bounded by engine output cap (8MiB stdout per program, 1MiB stderr). No unbounded stdout accumulation. CE code remains in correct editor.

## Engine internal contract

com.duipai.engine.RunEngine public class, constructed RunEngine(Path workRoot), implements AutoCloseable. Public synchronized Map<String,Object> start(String jobId, Map<String,String> codes, Map<String,Object> settings, String replaySeed, Consumer<Map<String,Object>> onUpdate). Returns immediate COMPILING snapshot. The consumer gets complete snapshots (state FINISHED on completion); snapshots should have id, metrics, results, codes and settings. public Map<String,Object> snapshot(String jobId); public void cancel(String jobId); public boolean isBusy(); public void close(). Backend enriches problemId, persists initial and final snapshot + immutable source/settings, listens for snapshots. Engine owns job scheduling, fresh subprocess per program per round, seed arithmetic (reject 64-bit overflow), javac in backend process via ToolProvider compiler with UTF-8 encoding, cancellation and descendant termination. Compare normalized output lines stripping trailing whitespace, CRLF and final blank lines ONLY. First detected failing completed round in parallel execution wins; cancel all remaining workers. For replay always include all outputs even PASS. maxOptimizedMs includes failed runtime. Cap JVM heap (128MiB), do not create command shells. Track all child processes for exit cleanup.

## Ownership

- backend agent: backend/pom.xml, backend config, com.duipai except engine/, REST/storage/auth/templates/tests.
- engine agent: backend/src/main/java/com/duipai/engine/, backend/src/test/java/com/duipai/engine/.
- frontend agent: frontend/ ONLY, own package.json with React/Monaco/Vite/markdown/KaTeX dependencies.
- root: electron/, root package.json scripts/, docs/, integration, build and packaging.
