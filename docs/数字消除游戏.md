# 数字消除游戏

列表 `arr` 包含范围 `[1, n]` 中的所有整数，并按严格递增顺序排列。

对 `arr` 交替执行以下操作：

1. 从左到右，删除第一个数字，再每隔一个数字删除一个，直到列表末尾。
2. 从右到左，删除最右侧的数字，再每隔一个数字删除一个。
3. 重复以上两步，直到只剩下一个数字。

给定整数 `n`，输出最后剩下的数字。

## 输入格式

输入一个整数 `n`。

## 输出格式

输出最后剩下的数字。

## 数据范围

`1 <= n <= 1000000`

## 样例 1

输入：

```text
1
```

输出：

```text
1
```

说明：`arr = [1]`，无需执行删除操作。

## 样例 2

输入：

```text
9
```

输出：

```text
6
```

说明：列表依次变为：

```text
[1, 2, 3, 4, 5, 6, 7, 8, 9]
[2, 4, 6, 8]
[2, 6]
[6]
```
