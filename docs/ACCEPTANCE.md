## 性能实测

环境：Windows 11，JDK 21.0.7；小数据场景，120 轮，每轮生成器、暴力解、优化解各新启一个 JVM。以下数值包含编译及 JVM 启动开销，来源见 [设计说明](DESIGN.md)。

| 并行度 | 总轮数 | 总耗时 | 编译耗时 | 平均速度 |
| --- | --- | --- | --- | --- |
| 4（默认） | 120 | 7482ms | 178ms | 16.04 轮/s |
| 1 | 120 | 本表未单列 | 本表未单列 | 5.29 轮/s |

默认并行度在本机达到“每秒 10 轮以上”的目标；单并行低于该目标。该结果针对测试机器与测试代码，不表示任意程序均可达到同样吞吐量。

## 运行边界与交付条件

- 运行环境为 Windows 10/11 与完整 JDK 21，后端、编译器和用户程序共用本机 JDK；本次实际验证平台是 Windows 11 / JDK 21.0.7。
- 前端、Monaco worker、KaTeX 和字体随 JAR/桌面程序本地打包。首次安装构建依赖需联网，交付版本运行无需 CDN。桌面“全资源本地加载”与实际便携程序本地 Monaco 加载均已通过。
- 后端仅监听 `127.0.0.1` 随机端口；所有 API、图片、SSE、导出与关闭接口验证每次启动生成的随机令牌，同源/明确开发来源之外的 Origin 被拒绝。
- 用户代码在独立进程运行，每个 JVM Java 堆上限 128MiB；stdout 最多 8MiB、stderr 最多 1MiB，超限终止。界面可导出的是完整**已捕获**内容，超出执行上限的部分不会保留。
- Windows Job Object 管理派生进程，取消、超时、输出超限、后端关闭时清理；后端也监视 Electron 父进程。引擎清理与桌面真实主进程异常退出路径均已通过。
- 这是运行自己信任的本地 Java 代码的工具，**没有操作系统沙箱**；128MiB 是 Java 堆限制，不是完整操作系统内存隔离。
- 并行执行保留最先检测到的失败，失败种子不保证最小。复现使用该种子与当前代码，历史代码快照仍可查看。
- 图片支持有效 PNG/JPEG/GIF，单文件最多 10MiB、1600 万像素，转存 PNG；GIF 保存首帧。
- 数据集中在一个本地目录，退出应用后复制整个目录即可备份。桌面默认目录、JDK 配置与启动命令见 [README](../README.md)。
- Windows x64 交付形态为未进行商业代码签名的便携程序 [Duipai-1.0.0-win-x64.exe](../release/Duipai-1.0.0-win-x64.exe)，实际解压/启动、对拍/历史、关闭/后端退出 4 项检查已通过。

交付文件与 SHA256 见 [release-manifest.json](release-manifest.json)；构建后端 JAR 与便携目录资源内 JAR 的 SHA256 一致。最终只读 WMI 检查确认本项目 Electron/Java 进程无残留。

v1 不包含其他语言、多解法、SPJ、浮点容差、交互题、函数模式、反例缩小、性能测试专用模式、断点调试、语义级补全、AI、多用户、联网或跨平台桌面支持，范围与原需求一致。

## 复验方式

在项目根目录、依赖已安装的情况下执行：

```powershell
npm test                 # 前端 10 项、TypeScript/构建、后端 21 项
npm run test:acceptance   # 真实 JVM / SQLite API 14 项，生成 docs/acceptance-results.json
npm run test:desktop      # Electron 桌面 10 项，生成 docs/desktop-results.json
npm run test:portable     # 实际便携 EXE 4 项，生成 docs/portable-results.json
npm run package           # Windows x64 便携程序
```

便携复验脚本为 [portable-smoke.mjs](../scripts/portable-smoke.mjs)。实现结构与资源限制见 [DESIGN.md](DESIGN.md)，接口、快照及 SSE 协议见 [CONTRACT.md](CONTRACT.md)，使用与备份见 [README.md](../README.md)。最终证据为 [backend-test-results.json](backend-test-results.json)、[frontend-test-results.xml](frontend-test-results.xml)、[acceptance-results.json](acceptance-results.json)、[desktop-results.json](desktop-results.json)、[portable-results.json](portable-results.json)。
