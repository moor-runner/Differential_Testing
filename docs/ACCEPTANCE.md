| 拖动后重启，布局恢复 | API 布局保存/恢复与桌面原生拖动/重启尺寸比较通过 | 通过 |
| 关闭窗口，后端随之退出 | API 关闭、桌面正常关闭/真实主进程异常退出、实际便携程序关闭及后端退出通过 | 通过 |

桌面脚本的“10 项”按实际交互流程组合测试，和原文的“10 项标准”不是逐项同名对应；上表说明两者之间的验证关系。

环境：Windows 11，JDK 21.0.7；小数据场景，120 轮，每轮生成器、暴力解、优化解各新启一个 JVM。以下数值包含编译及 JVM 启动开销，来源见 [设计说明](DESIGN.md)。

| 并行度 | 总轮数 | 总耗时 | 编译耗时 | 平均速度 |
| --- | --- | --- | --- | --- |
| 4（默认） | 120 | 7482ms | 178ms | 16.04 轮/s |
| 1 | 120 | 本表未单列 | 本表未单列 | 5.29 轮/s |

## 运行边界与交付条件

- 运行环境为 Windows 10/11 与完整 JDK 21，后端、编译器和用户程序共用本机 JDK；本次实际验证平台是 Windows 11 / JDK 21.0.7。
- 前端、Monaco worker、KaTeX 和字体随 JAR/桌面程序本地打包。首次安装构建依赖需联网，交付版本运行无需 CDN。桌面“全资源本地加载”与实际便携程序本地 Monaco 加载均已通过。
- 后端仅监听 `127.0.0.1` 随机端口；所有 API、图片、SSE、导出与关闭接口验证每次启动生成的随机令牌，同源/明确开发来源之外的 Origin 被拒绝。
- 用户代码在独立进程运行，每个 JVM Java 堆上限 128MiB；stdout 最多 8MiB、stderr 最多 1MiB，超限终止。界面可导出的是完整**已捕获**内容，超出执行上限的部分不会保留。
- Windows Job Object 管理派生进程，取消、超时、输出超限、后端关闭时清理；后端也监视 Electron 父进程。引擎清理与桌面真实主进程异常退出路径均已通过。
- 这是运行自己信任的本地 Java 代码的工具，**没有操作系统沙箱**；128MiB 是 Java 堆限制，不是完整操作系统内存隔离。
- 并行执行保留最先检测到的失败，失败种子不保证最小。复现使用该种子与当前代码，历史代码快照仍可查看。
- 图片支持有效 PNG/JPEG/GIF，单文件最多 10MiB、1600 万像素，转存 PNG；GIF 保存首帧。
- 数据集中在一个本地目录，退出应用后复制整个目录即可备份。桌面默认目录、JDK 配置与启动命令见 [README](../README.md)。
- Windows x64 交付形态为未进行商业代码签名的便携程序 [Duipai-1.0.4-win-x64.exe](../release/Duipai-1.0.4-win-x64.exe)，实际解压/启动、图片/预览、对拍/历史、显示模式、OCR、AI 入口与加密设置及日志入口、关闭/后端退出 7 项检查已通过。

交付文件与 SHA256 见 [release-manifest.json](release-manifest.json)；构建后端 JAR 与便携目录资源内 JAR 的 SHA256 一致。桌面和便携验收核对了各自启动的后端随窗口关闭而退出。

v1 不包含其他语言、多解法、SPJ、浮点容差、交互题、函数模式、反例缩小、性能测试专用模式、断点调试、多用户或跨平台桌面支持。1.0.3 按用户后续要求加入可选的联网 AI 整理；本地对拍和图片 OCR 继续可离线使用。1.0.6 加入基于本地 JDK 的单文件 Java 语义补全和即时检查，范围是当前 Main.java 与 JDK 标准库，不包含跨文件项目索引、重构和调试器。

## 复验方式

在项目根目录、依赖已安装的情况下执行：

```powershell
npm run test:ai           # OpenAI 兼容模拟接口桌面 18 项，生成 docs/ai-results.json

```
