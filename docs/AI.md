# AI 整理题面

1.0.3 增加可选的 AI 整理，适合把 OCR 中混杂的考试信息、代码栏、水印和断句整理为可读的编程题题面。本地「识别」和「整理」继续可离线使用。

## 速度、进度与日志（1.0.4）

调用 DeepSeek 官方服务（`api.deepseek.com`）时自动发送 `thinking:{type:"disabled"}`，关闭整理任务不需要的长推理。[DeepSeek 官方说明](https://api-docs.deepseek.com/guides/thinking_mode/) 表明默认开启思考，使用这一参数可关闭；其他 OpenAI 兼容服务保留通用参数。

服务支持流式返回时，窗口会显示实际接收阶段、已耗时、首响应耗时与接收字数。「处理记录」包含请求编号、连接、收到响应、生成、完成或失败的时间记录。只有完整回复通过检查后才能应用，流中断、被截断或发生错误时原题面保留。忽略流式参数而返回完整 JSON 的兼容服务仍可使用。取消会终止本次上游请求，随后可以重新整理。

点击整理/设置窗口中的「查看后台日志」或工作台底部「后台日志」，打开数据目录中的 `backend.log`。当前项目启动脚本的日志位于 `data/backend.log`。日志记录请求编号、阶段、HTTP 状态、耗时和字符统计，不记录密钥、原文、回复正文或推理内容。日志按请求编号查找，界面的失败信息和记录在失败后保留，便于检查。

2026-10-07 使用当前已配置的 DeepSeek 服务做一次极短的非思考流式诊断，只发送「只回复 OK」：首个输出 726 ms，总耗时 766 ms，HTTP 200，推理字符数 0。详见 [测量记录](ai-provider-timing.json)。此结果是短消息的实际测量；完整题面需要更多输出，耗时还取决于服务负载和网络。本次没有重发用户题面，也没有测量旧请求的思考阶段，因此不能据此判定先前几分钟全部耗在思考中。

## 配置和使用

1. 点击题面底部的齿轮「AI 设置」。填写 **API 地址**、**模型名称**、**API Key**。
2. 官方接口地址填写 `https://api.openai.com/v1`；第三方兼容服务填写其提供的基础地址。也支持末尾斜杠、完整 `/chat/completions` 地址和自定义代理路径。模型名称填写该服务支持的名称。
3. 点击「保存配置」。可点击「保存并测试」验证地址、模型和认证；该按钮会发送一条简短测试消息。
4. 点击「AI 整理」。左侧显示待发送文字，可先删掉无关信息；点击「开始整理」后生成右侧的分区域结果。
5. 核对题目描述、输入输出、数据范围和样例数字，直接编辑各区域。取消勾选的区域保留原文；点击「应用到题面」才会替换文字并自动保存。题面底部的撤销按钮可恢复本次应用前的内容。

只有图片时，先点击「识别」提取本地文字；识别窗口中的「AI 整理识别结果」可整理已勾选的识别区域。AI 结果先更新识别草稿，返回后仍需点击外层「应用到题面」。

## 文字和密钥

整理请求只包含预览窗口中的题面文字，使用文本 Chat Completions 接口；原图、独立笔记小节、其他自定义根级小节和三个编辑器中的程序不发送。题面必要的代码、公式和样例数据保留在文字中。AI 应用保留原图、独立笔记，以及未返回或未勾选的原有区域。请在发送前检查左侧文字，正文中混入的内容可以直接删除。

Key 单独保存于数据目录的 `ai-settings.json`，由当前 Windows 账户的 DPAPI 加密，GET 接口和界面只返回是否已配置。Key 输入框留空保存会保留旧值，填写新值可替换；勾选「清除已保存的 API Key」可移除。把数据复制到另一个 Windows 账户后，需要重新填写 Key。

保存、打开配置、打开整理预览不会调用模型。点击「开始整理」或「保存并测试」才连接所配置的服务。AI 的数字和条件仍需校对；整理指令要求缺失、冲突或无法辨认的内容标为「【待确认】」，避免自行补写。取消、认证失败、空回复和截断回复都不会自动写入题面。

## 接口和验证

后端发送 `POST /chat/completions`，带 `Authorization: Bearer …`，JSON 包含 `model`、`messages` 和 `stream:true`。采用 [OpenAI Chat Completions 接口格式](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)，上游按 [流式数据格式](https://api-docs.deepseek.com/api/create-chat-completion/) 返回增量；本机整理接口仍在完整处理后返回 JSON。DeepSeek 官方服务额外发送关闭思考的参数。不自动跟随重定向；请求最多 120 秒，输入最多 100000 字符，响应最多 2 MiB。

自动化命令：`npm --prefix frontend test`、后端 Maven 测试、`npm run test:ai` 和 `npm run test:portable`。AI 桌面验收使用隔离数据目录、本机模拟服务和假 Key，覆盖配置加密、连接请求、取消与错误、分区校正、选择应用、撤销、保存和重启。结果见 [ai-results.json](ai-results.json)；实际预览见 [ai-preview.png](ai-preview.png)。真实服务的模型权限和可用额度由你填写的配置决定。

1.0.4 验证：前端 72/72、后端 63/63（含 33 项 AI 测试）、AI 桌面专项 18/18、本地 OCR 桌面回归 12/12、实际便携 EXE 验收 7/7 通过。AI 桌面验证真实 SSE 进度与中文分包、取消后立即重试、401 只返回响应头时立即报错并关闭上游、重试失败不应用旧草稿、日志隐私及固定日志文件 IPC；识别草稿的未选范围、勾选状态和原图区域标记继续保留。便携程序验证打包的 Key 加密、清除、整理入口和后台日志路径。
